# CODSOFT Java Development Internship — Tasks 1–3

This repository contains my completed Java Development Internship tasks for CODSOFT.

## Tasks Completed

### Task 1 — Number Game
A number guessing game that:
- Generates a random number from 1 to 100
- Takes guesses from the user
- Gives "too high" or "too low" feedback
- Limits the number of attempts
- Supports multiple rounds
- Tracks the score

### Task 2 — Student Grade Calculator
A program that:
- Takes marks for each subject
- Calculates total marks
- Calculates average percentage
- Assigns a grade
- Validates marks from 0 to 100

### Task 3 — ATM Interface
A menu-driven ATM application that:
- Withdraws money
- Deposits money
- Checks account balance
- Validates invalid amounts and insufficient balance
- Uses separate `BankAccount` and `ATMInterface` classes

## How to Run

Make sure Java JDK is installed.

Example:

```bash
javac NumberGame.java
java NumberGame
```

For Task 2:

```bash
javac StudentGradeCalculator.java
java StudentGradeCalculator
```

For Task 3:

```bash
javac ATMInterface.java
java ATMInterface
```
